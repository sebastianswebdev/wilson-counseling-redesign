WILSON COUNSELING — LOCAL REDESIGN

PAGBUKAS SA MAC
I-double-click ang Start.command. Bubukas ang local website sa browser.
Python 3 lang ang kailangan. Walang npm install o build step.

Puwede ring buksan nang direkta ang index.html sa browser.

MANUAL NA PAG-RUN
Sa folder na ito, patakbuhin:
python3 start.py

PARA HUMINTO
Pindutin ang Control+C sa Terminal window ng preview.

MGA FILE
index.html   — navigation at pangunahing page structure
styles.css   — responsive design at animations
app.js       — local navigation, filters, search, at dialogs
data.js      — imported na original website content
assets/      — lokal na images at fonts

NILALAMAN
46 imported pages: services, five therapist biographies, FAQ and rates,
contact information, resources, at nine journal articles. May bagong
homepage, services directory, therapists directory, at resources hub.

Pareho ang aqua/coral branding at original images ng Wilson Counseling.
Naka-save locally ang images at fonts. Walang analytics o trackers.
Sinusuportahan ang mobile, keyboard navigation, at reduced motion.

Redesign concept by @sebastianswebdev.
Hiwalay na demo ito para sa owner review.
Ang appointment button ay may malinaw na link papunta sa original Jane
booking site. Ang email, phone, text, YouTube, external articles,
assessments, referral form, at legal links ay nagbubukas sa kani-kanilang
original destinations. Walang form na nagpapanggap na nagsend o nagbook.

Ang original homepage video ay hindi available sa source; nakalink ang
Wilson Counseling YouTube channel. Ang iba pang blog posts at source
links na wala sa local copy ay nagbubukas sa original website.
